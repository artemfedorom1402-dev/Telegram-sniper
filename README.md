# Telegram Username Sniper Bot

Ищет свободные Telegram-юзернеймы и проверяет их ликвидность на Fragment.

## Как это устроено

- **Проверка "свободен ли ник"** делается не через обычный Bot API (он этого не умеет),
  а через MTProto-метод `account.checkUsername` от имени обычного Telegram-аккаунта
  (библиотека Telethon). Поэтому кроме токена бота нужен ещё `api_id`/`api_hash`.
- **Проверка ликвидности на Fragment** — парсинг страницы `fragment.com/username/<name>`.
  Официального API у Fragment нет, так что это best-effort: если Fragment поменяет
  вёрстку, парсинг в `fragment_checker.py` может потребовать правок.

## Установка

1. **Перевыпустите токен бота.** Тот, что вы прислали в чат, уже засвечен —
   зайдите в @BotFather → выберите бота → Bot Settings → Revoke current token.

2. Получите `api_id` и `api_hash` для Telethon на https://my.telegram.org
   (раздел "API development tools", обычный номер телефона, не бот).

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и заполните:
   ```bash
   cp .env.example .env
   ```

5. Запустите:
   ```bash
   python bot.py
   ```
   При первом запуске Telethon попросит номер телефона и код из Telegram —
   это разовая авторизация, дальше сессия сохранится в файл `checker_session.session`.

## Команды бота

- `/check ник1 ник2 ...` — проверить конкретные юзернеймы
- `/scan длина [сколько_найти]` — сгенерировать и найти свободные варианты заданной длины
- `/monitor ник` — сообщить, когда ник освободится (фоновая проверка раз в `MONITOR_INTERVAL_SECONDS`)
- `/unmonitor ник` — снять с наблюдения
- `/list` — список наблюдаемых ников

## Важные оговорки

- Массовая проверка ников через MTProto может упереться в `FloodWait` от Telegram —
  бот это обрабатывает, но не злоупотребляйте частотой (особенно в `/scan`).
- Автоматический сбор данных с Fragment может противоречить условиям использования сайта —
  используйте на свой страх и риск и не создавайте чрезмерную нагрузку на сервис.
- Файл `checker_session.session` — это фактически доступ к вашему Telegram-аккаунту,
  храните его так же, как пароль, и не публикуйте.
